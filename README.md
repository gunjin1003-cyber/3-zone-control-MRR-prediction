# SiO2 CMP 3-Zone 압력 → MRR 프로파일 예측

21장의 웨이퍼를 3-zone 압력 조건으로 연마하고 `-74 ~ +74 mm` 43개 지점에서 측정한
MRR 데이터(`data/Train_1.csv`)로 학습하여, **압력을 입력하면 MRR 프로파일 전체를
예측**하는 도구입니다.

```bash
pip install -r requirements.txt
python scripts/train.py                      # 모델 학습 → models/mrr_model.pkl
python scripts/predict.py 2.0 2.2 2.0        # Zone1 Zone2 Zone3 [psi] → 프로파일
python scripts/optimize.py --mode uniform    # 역방향: 균일도 최적 압력 탐색
```

---

## 1. 결론 먼저 — 어떤 모델이 가장 강력한가

**반경별 선형 영향함수(zone influence function) 모델**입니다.
딥러닝·부스팅·랜덤포레스트가 아닙니다. 이유는 데이터 구조 자체에 있습니다.

```
MRR(r) = a(r) + K₁(r)·P₁ + K₂(r)·P₂ + K₃(r)·P₃   ( + 2차·교호항 )
```

`K_z(r)` = "존 z의 압력을 1 psi 올리면 반경 r에서 MRR이 몇 A/min 오르는가",
즉 **물리적으로 해석 가능한 영향함수**입니다. 데이터에서 학습된 결과가
`figures/02_influence_functions.png` 이고, 존 경계와 정확히 일치합니다 —
Zone 3는 `|r| ≤ 55`에서 평평하게 ~470, Zone 2는 `|r| ≈ 60~64`에서 ~490으로 솟고,
Zone 1은 `|r| ≥ 70`에서 급격히 올라 r=74에서 2250 A/min/psi 에 달합니다.
누가 가르쳐 준 적 없는 존 배치를 데이터가 스스로 복원합니다.

여기에 두 가지 물리 사전지식을 규제(regularization)로 얹은 것이 최종 모델
(`mrrpred.models.SymmetryRidge`)입니다.

| 물리 사전지식 | 구현 | 효과 |
|---|---|---|
| 연마는 회전평균 → 응답은 `\|r\|`의 함수 | 프로파일을 대칭/반대칭으로 분해, 대칭 성분은 접힌 반경에서 적합 | 반경당 표본 2배, 노이즈 1/√2 |
| 좌우 비대칭은 압력이 아니라 헤드 틸트 등 **장비 고유 signature** | 반대칭 성분을 rank-1(고정 형상 × 압력 선형)로 강하게 규제 | 자유 파라미터 21개 회귀 → 4개 |

두 번째는 데이터로 검증한 것입니다. 동일 압력 반복 웨이퍼(#1,2,3 / #19,20,21) 사이의
비대칭 성분 **상관계수가 0.85~0.99**로 재현되고, SVD 1개 성분이 비대칭 분산의
**88.6%** 를 설명합니다. 즉 좌우 비대칭은 노이즈가 아니라 결정론적 신호이므로
**대칭화(symmetrize)해서 버리면 실제 신호를 버리는 것**입니다.

**최종 성능** (본 적 없는 압력 조건 기준):

| | 전체 | edge exclusion 4 mm (`\|r\| ≤ 70`) |
|---|---:|---:|
| RMSE | 163.2 A/min | **67.8 A/min** |
| MAPE | 5.83 % | **4.53 %** |
| 측정 재현성 한계 | 118.4 A/min | — |

## 2. 왜 복잡한 모델이 이기지 못하는가

### (a) 표본이 21장, 고유 압력 조건은 16개뿐

입력 차원 3~4, 출력 차원 43, 표본 21. 트리·신경망이 학습할 데이터가 근본적으로 없습니다.

### (b) 프로파일이 사실상 2~3차원

| 주성분 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| 설명분산 누적 (%) | 71.1 | **94.2** | 97.5 | 98.9 |
| 재구성 RMSE (A/min) | 205 | **91** | 60 | 39 |

2개 성분이면 재구성 오차 91 A/min인데, 아래 (c)의 **측정 재현성 한계가 118 A/min**
입니다. **3차원을 넘는 표현력은 노이즈를 학습하는 것**과 같습니다.

### (c) 측정 재현성이라는 넘을 수 없는 하한

동일 압력으로 반복 연마한 웨이퍼들(#1,2,3 / #4,5 / #19,20,21)의 순수 오차:

| 구간 | 반복실험 노이즈 (A/min) |
|---|---|
| 중심 `\|r\| ≤ 50` | **40** |
| 에지 `\|r\| ≥ 70` | **162** |
| r = ±74 (최외곽) | **287 ~ 500** |
| 전체 | **118** |

어떤 모델도 이보다 잘 맞출 수 없습니다. 더 잘 맞았다면 그건 과적합입니다.

## 3. 실제 성능 — 모델 벤치마크

평가는 **Leave-One-Design-Out 중첩 교차검증**입니다. 동일 압력 조건의 반복 웨이퍼를
통째로 묶어서 빼기 때문에, "본 적 없는 압력 조건"에 대한 정직한 성능입니다.
하이퍼파라미터도 매 fold 내부에서 다시 선택하므로 선택 편향이 없습니다.

### 3.1 하이퍼파라미터 고정 비교 (가장 공정한 비교)

`python scripts/benchmark_fixed.py` · `±SE` 는 16개 설계조건 fold에 대한 부트스트랩 표준오차

| 모델 | RMSE (A/min) | ±SE | MAPE | 중심 | 중간 | 에지 |
|---|---:|---:|---:|---:|---:|---:|
| **대칭성 능형회귀 [quad]** | **163.2** | 23.8 | 5.83% | 48.9 | 83.1 | 318.2 |
| PLS 3성분 [quad] | 164.0 | 22.6 | 5.73% | 43.4 | 87.3 | 320.3 |
| 반경별 능형회귀 [quad] | 168.1 | 26.0 | 6.59% | 63.2 | 87.6 | 322.3 |
| 반경별 능형회귀 [zone] | 169.2 | 28.1 | 6.13% | 52.6 | 82.1 | 330.5 |
| 반경별 능형회귀 [phys] | 174.1 | 29.4 | 5.97% | 44.8 | 83.9 | 343.1 |
| 저계수(rank-3) 능형회귀 | 178.7 | 28.3 | 6.59% | 57.4 | 89.1 | 347.7 |
| PLS 2성분 [zone+ring] | 181.4 | 26.5 | 8.40% | 103.6 | 104.4 | 325.4 |
| 신경망 MLP | 195.4 | 31.7 | 7.06% | 66.4 | 85.4 | 382.4 |
| 가우시안 과정 (GPR) | 202.3 | 32.4 | 6.80% | 55.7 | 87.3 | 400.4 |
| 랜덤포레스트 | 227.5 | 31.5 | 9.82% | 110.5 | 124.3 | 422.3 |
| *Preston 스케일 (기준선)* | 282.6 | 30.4 | 11.72% | 104.4 | 131.8 | 547.4 |
| *평균 프로파일 (기준선)* | 408.7 | 42.3 | 24.65% | 278.5 | 307.7 | 664.6 |
| **반복실험 순수오차 (하한)** | **118.4** | — | — | **40.0** | **46.0** | **162.0** |

읽는 법이 중요합니다.

- **선형/저차원 모델 10종이 1 SE(±24) 안에 몰려 있습니다.** 이들 사이의 차이는
  통계적으로 의미가 없습니다. 어느 걸 써도 됩니다.
- **랜덤포레스트·GPR·MLP는 명확히 열등합니다** (1.5~4.6 SE 차이). 표본이 21개인
  문제에서 유연한 비선형 모델은 손해만 봅니다.
- 최고 모델도 하한(118)의 1.38배입니다. **이 데이터로 얻을 수 있는 성능의 대부분에
  이미 도달했습니다.**

### 3.2 중첩 교차검증 (하이퍼파라미터 탐색까지 포함한 절차의 정직한 성능)

fold마다 내부 CV로 하이퍼파라미터를 다시 고르는, 선택 편향이 제거된 평가입니다.

| 모델군 | LOGO-CV | LOWO-CV |
|---|---:|---:|
| 대칭성 능형회귀 | 177.9 | 166.6 |
| 저계수 능형회귀 | 178.6 | 167.1 |
| 반경별 능형회귀 (선형) | 175.6 | 159.9 |
| 반경별 + 2차/교호 | 174.9 | 163.4 |
| PCA + 능형회귀 | 173.2 | 166.7 |
| PLS | 168.4 | 162.1 |
| PCA + 가우시안과정 | 191.2 | 188.8 |
| 가우시안과정 다출력 | 202.2 | 194.0 |
| 커널능형회귀 (RBF) | 220.4 | 207.3 |
| 반경별 로그(곱셈형) | 192.5 | 188.6 |

3.1의 163과 3.2의 178이 다른 이유는 **하이퍼파라미터 선택 자체가 오차를 만들기
때문**입니다. 16개 fold밖에 없으니 선택이 흔들립니다. 실제 배포 성능은 이 사이,
**대략 165~180 A/min (MAPE 5.8~6.5%)** 로 보는 것이 정직합니다.

다행히 선택은 안정적입니다. 중첩 CV 16개 fold 중 **13개가 동일한 설정**
(`feat=quad, rank=1, alpha=1`)을 골랐고, 이것이 배포 모델의 설정입니다.

### 3.3 외삽 스트레스 테스트

`python scripts/stress_extrapolation.py` — 저압군(1.3–2.5 psi, 15장)과
고압군(2.7–3.2 psi, 6장)을 통째로 나눠 서로를 예측시킵니다.

| 모델 | 저압 → 고압 | 고압 → 저압 | 평균 MRR 편향 (저→고) |
|---|---:|---:|---:|
| 반경별 능형회귀 [quad] | **252.6** | 1546.7 | +22 |
| 대칭성 능형회귀 [quad] | 255.0 | 1847.0 | +51 |
| 반경별 능형회귀 [zone] | 269.5 | 1201.1 | −82 |
| PLS 3성분 [quad] | 270.4 | 5250.2 | +61 |
| 가우시안 과정 | 465.4 | 660.2 | −412 |
| 랜덤포레스트 | 494.2 | 641.3 | −436 |

- **위쪽 외삽(저압→고압)은 선형 모델이 안전합니다.** 1.3–2.5 psi만 보고 3.2 psi를
  예측했는데 평균 MRR 편향이 1728 대비 +22 (1.3%)에 불과합니다. Preston 법칙
  (MRR ∝ P)이 실제로 성립한다는 증거입니다.
- **랜덤포레스트·GPR은 외삽을 아예 못 합니다.** 학습 평균으로 수렴해 −436의
  구조적 편향이 생깁니다. 압력을 새로 조합해 보는 것이 목적인 이 문제에서
  치명적인 성질입니다.
- 아래쪽 열(고압→저압)이 크게 무너지는 것은 모델 탓이 아닙니다. 고압군은 웨이퍼
  6장·고유조건 4개뿐이고 세 존이 함께 움직여 기울기 자체가 결정되지 않습니다.

## 4. 오차가 어디에 남아 있는가

`figures/04_error_vs_noise.png` — 반경별 CV 오차와 반복실험 노이즈를 겹쳐 그린 그림입니다.
두 곡선이 거의 포개집니다.

| 구간 | CV 오차 | 노이즈 하한 | 비율 |
|---|---:|---:|---:|
| 중심 `\|r\| ≤ 50` | 48.9 | 40.7 | **1.20** |
| 중간 `55 ~ 68` | 83.1 | 46.4 | 1.79 |
| 에지 `\|r\| ≥ 70` | 318.2 | 211.5 | 1.50 |
| r = ±74 (최외곽) | 589.8 | 407.4 | 1.45 |

**중심부는 개선 여지가 거의 없습니다.** 모델 오차가 같은 조건으로 두 번 연마했을 때의
차이의 1.2배 수준입니다. 전체 RMSE 163을 키우는 것은 사실상 최외곽 4개 점(±72~74)
뿐이고, 그 지점은 **측정 자체의 산포가 400 A/min** 입니다.

실무에서 흔히 쓰는 edge exclusion 4 mm(`|r| ≤ 70`)를 적용하면:

```
CV RMSE = 67.8 A/min,  MAPE = 4.53 %   (평균 MRR 1164)
```

**공정 판단에 쓰기 충분한 정확도입니다.**

## 5. 사용법

### 순방향 예측

```bash
$ python scripts/predict.py 2.0 2.2 2.0        # Zone1 Zone2 Zone3 [psi]

입력 압력 : Zone1=2.0  Zone2=2.2  Zone3=2.0 psi   (이 모델은 링 압력을 사용하지 않습니다)
모델 CV   : RMSE 163.2 A/min (5.8%)

  r(mm)      MRR    95% 구간
      74    2879.2   [ 1721.6,  4036.8]
      73    2299.2   [ 1748.5,  2849.9]
       ...
       0    1032.7   [  959.9,  1105.5]
       ...
  평균 MRR      :   1205.8 A/min
  불균일도(1s)  :    36.45 %
```

- **존 압력 3개만 입력하면 됩니다.** 최종 모델(`feat=quad`)은 링 압력을 쓰지 않습니다.
  링 압력을 쓰는 설정(`zone+ring`, `quad+ring`, `phys`)을 고르면 `--ring` 으로 넣거나,
  생략 시 `ring = 0.309 + 0.216·Z1 + 0.306·Z2 + 0.381·Z3` (R²=0.92, RMSE 0.12 psi)로
  자동 보간합니다. 링 압력을 특징에 넣어도 성능은 좋아지지 않았습니다
  (존 압력과 거의 공선이라 분산만 늘어남).
- 95% 구간은 교차검증 잔차에서 얻은 **반경별** 불확실도입니다. 에지에서 넓습니다.
- 학습 설계점에서 0.3 psi 이상 떨어지면 외삽 경고를 출력합니다.
- 옵션: `--csv out.csv` 결과 저장, `--plot out.png` 프로파일 그림.

### 역방향 (레시피 탐색)

```bash
python scripts/optimize.py --mode uniform --target-mean 1200 --edge-exclude 70
python scripts/optimize.py --mode profile --target-csv target.csv
```

`--edge-exclude 70` 은 edge exclusion 3 mm 를 가정하고 `|r| ≤ 70` 만으로
균일도를 계산합니다. 실무에서는 이쪽이 의미 있는 지표입니다.

## 6. 이 데이터의 한계 (중요)

1. **압력 공간이 두 덩어리로 갈라져 있습니다.** 웨이퍼 1–15는 1.3–2.5 psi,
   16–21은 2.7–3.2 psi 이고 그 사이가 비어 있습니다. 2.5–2.7 psi 구간 예측은
   보간이 아니라 사실상 외삽입니다.
2. **존별 단독 변화 조건이 각 1~2개뿐**입니다. Zone3=1.5 는 웨이퍼 #9 하나뿐이라
   그 조건을 빼고 예측하면 오차가 286 A/min 으로 뜁니다(전체 평균의 1.6배).
3. **존 압력끼리 상관되어 있습니다.** 고압군은 세 존이 함께 올라갑니다.
   그래서 `figures/02` 의 Zone2 영향함수가 최외곽에서 음수로 나오는데,
   이는 물리가 아니라 다중공선성 아티팩트로 보는 것이 안전합니다.

### 다음 실험을 설계한다면

가장 효율이 높은 추가 실험은 **각 존을 독립적으로 흔드는 직교 설계**입니다.
현재 데이터의 병목은 모델이 아니라 설계 공간이기 때문입니다. 구체적으로:

- 2.5 ~ 2.7 psi 공백 구간 채우기 (2~3 조건)
- Zone3 저압(1.5) 반복 및 Zone3 단독 수준 추가
- 세 존을 서로 반대 방향으로 움직이는 조건 (상관 제거)
- r = ±72~74 구간 측정점 반복 측정 (여기가 노이즈의 원천)
